# 生成方式の改訂: Codex app serverと人型skill

2026-09-12。外部3D生成APIからCodex app server経由の `dotforge-humanoid` へ移行する。プロジェクト設定、同一モデルの8方向、実64×64、パーツ管理、候補と採用の分離を維持する。

- ブラウザから端末内bridgeへ説明・特徴・参照・プロジェクトスタイル・人型skill IDを送る。クラウドは依頼と完成モデルを利用者別に保存する。
- 16関節と全パーツの追従先を持つ構造化JSONを生成する。サンプルは品質と骨格接続の参考とし、単純な色替えを新しいデザインとしない。
- 指定styleで静止8方向と基本4動作の344画像を検証する。技術検証と実画像レビューの両方に合格した候補のみ返す。最大2回の修正でも未解決なら失敗とする。
- 同じIDは重複実行しない。取消はapp serverへ伝える。ブラウザを閉じても端末上で継続する。bridge再起動後は自動で新しい生成を始めない。
- 旧外部APIキー、credits、課金同意、生成経路を削除する。既存保存素材の読み込みに必要なsource値は互換用に残す。
- 初回は人型のみ。動物は将来、独立したskillと骨格・出力契約・検証器を登録する。

画素寸法・余白・パレット・接地・到達範囲・床貫通は自動検証する。自己交差・入力忠実度・美的品質を完全には保証しない。採用前に利用者が確認する。

制作手順の正本は `skills/dotforge-humanoid/SKILL.md`、接続と制約はREADMEに記録する。
