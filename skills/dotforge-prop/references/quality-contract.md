# Static prop model contract v1

The model has `id`, `name`, `prompt`, `features`, and `parts`. Each part has a unique ASCII `id`, `shape` (`box`, `ellipsoid`, `cylinder`, `cone`), absolute `position`, full-extent `size`, opaque `color` in `#rrggbb`, and optional XYZ `rotation` in **radians**. Structured app output requires rotation, so use `[0,0,0]` for unrotated pieces. Do not include `rig`, `bone`, or `motionCorrections`.

Use 1–100 purposeful parts. A part ID identifies the same physical component in every direction and is used for manual color and shape edits. Name it for its function and side, such as `tabletop`, `front-left-leg`, `rear-right-leg`, `backrest`, `lid`, `front-latch`, `rear-hinge-left`. The lower part count bound supports simple objects; the maximum is a budget, not a target.

Coordinates: +X is object-left, −Y is front, +Z is up. Ground is Z=0; centered furniture should sit on the ground with its footprint around X/Y=0. Positions are absolute centers, not offsets from another part. Keep vertices at Z≥−0.015. Boxes span size/2 around their center; cylinders and cones point along local Z before rotation. Dimensions are positive, between .005 and 3; positions and rotations are finite and bounded to ±5 by the input contract.

Default style is 30° downward elevation, 20 pixels per model unit, light 225°/45°, a 32-color palette, 1px outline, and ground anchor [32,52]. A useful starting envelope is about 1.6 wide × 1.6 deep × 1.5 tall, but the actual projection and supplied style determine fit. Render all directions to check the diagonal footprint. Scale all geometry together if necessary; preserve proportions and meaningful leg/support thickness.

Acceptance: the same model with one fixed palette, camera, scale, and world-space light produces eight views S, SE, E, NE, N, NW, W, SW. Each view has exactly 4096 palette-indexed pixels, transparent index 0, no antialiasing or partial alpha, at least a 2px transparent outer margin, and no clipping. Inspection always covers all eight directions even when the requested deliverable is front-only. Native static sheet is 512×64. The zoom sheet is the same eight frames in a 4×2 grid enlarged 4 times without interpolation; it is a review aid, not the asset resolution.

The artifact kind and validation version are `static-prop-v1`, skill version `1.0.0`, renderer version is the studio's RENDERER_VERSION, validation frame count is 8. The legacy shared `validation.motion` field carries `static-prop-v1`; it does not imply animations. The server independently rechecks the part contract, floor penetration, palette, margins, and clipping. Visual review must still catch disconnected supports, missing required hardware, unreadable clusters, incorrect materials, and invented features. No automated score certifies aesthetic quality or user intent.
